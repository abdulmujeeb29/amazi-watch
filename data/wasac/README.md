# WASAC data (not in Git)

This folder is git-ignored. Only this README is committed.

WASAC's Remera branch shared these files with us for academic use only. We agreed to **report only aggregated results**. So:

- Don't commit these files, paste rows into issues or chats, or put them in a public notebook output.
- Figures and tables in the report and slides must be aggregated (counts, medians, shares), not individual records.

## How to get the files

Download them from the team Drive folder (ask Abdulmujeeb for the link) into this folder:

```
data/wasac/
├── leaks/
│   └── Leakage_data_under_kimironko_sector.xlsx
└── rationing/
    ├── Gahunda_yisaranganganya_Nyakanga_13-19-2026_F.xlsx
    ├── Gahunda_yisaranganganya_Nyakanga_03-09th_Aug_2026.xlsx
    └── Gahunda_yisaranganganya_17-23rd_August_2026_final.xlsx
```

## What's in them

| File | Contents |
|---|---|
| `leaks/Leakage_data_under_kimironko_sector.xlsx` | 94 leak repair records, Kimironko sector, 5 Oct – 19 Nov 2026. One sheet, 19 fields: cell, village, report / repair / close times, and (when filled in) pipe diameter, material and cause. |
| `rationing/…13-19-2026_F.xlsx` | Remera rotation for 13–19 July 2026 |
| `rationing/…03-09th_Aug_2026.xlsx` | Two sheets: 27 July – 2 Aug 2026, and a second (slightly different) version of 13–19 July |
| `rationing/…17-23rd_August_2026_final.xlsx` | Despite the file name, the sheet inside is **10–16 Aug 2026** |

The rotation sheets list which of the 39 Remera areas get water on each day.

**Note on file names:** WASAC sent several copies of these files. The `_1` / `_2` versions were byte-identical duplicates and were dropped. The file names don't always match the week inside, so go by the sheet name.
